# Portfólio Pessoal

Este projeto tem como objetivo apresentar minha trajetória como estudante de Análise e Desenvolvimento de Sistemas (ADS), reunindo meus conhecimentos, habilidades e projetos desenvolvidos na área de tecnologia.

## Tecnologias Utilizadas

- HTML5
- CSS3

## Objetivos

Praticar os conhecimentos adquiridos.
Apresentar projetos pessoais e acadêmicos.
Desenvolver minhas habilidades em programação.
Construir minha identidade profissional na área de tecnologia.
